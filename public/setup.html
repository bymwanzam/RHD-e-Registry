Connect the MySQL database

The e-Registry stores its letters, officers and audit trail in a MySQL database on your hosting. Create it first in cPanel → MySQL® Databases (database, user, and "Add User To Database" with ALL PRIVILEGES), then enter the details here.

In cPanel → File Manager, open the file SETUP-KEY.txt and copy the key. This proves you manage the hosting.
cPanel adds your username in front, e.g. cpaneluser_eregistry.
Keep "localhost" on cPanel hosting.
